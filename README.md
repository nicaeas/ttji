# 天天记 · 微信笔记小程序

一款免登录、离线可用、数据留在本机的轻量笔记小程序。打开即写，支持标签、图片与语音附件、快速模板、回收站、按标签/月份筛选、分享为图片。

需求、用例与验收标准见 [需求分析.md](./需求分析.md)。

## 功能一览

**基础（v1）**

- ✅ 新建笔记：标题（可选，≤50 字）+ 正文（不限长）
- ✅ 编辑笔记：回填内容，保存后自动更新时间与排序
- ✅ 笔记列表：置顶优先，其余按最后编辑时间倒序，卡片显示摘要与人性化时间（今天/昨天/日期）
- ✅ 关键词搜索：标题 + 正文模糊匹配，实时过滤
- ✅ 置顶/取消置顶：长按列表项操作
- ✅ 空状态：无笔记引导创建、搜索无结果提示

**内置日记（2026-10 导入）**

- ✅ 首次启动自动播种 `data/seed-diary.js` 中的 **47 篇历史日记**（2026-06-13 ~ 2026-10-08，正文 28383 字，一字不差）
- ✅ 分类名自动转为标签：生活 45篇 / 重要 1 篇 / 工作 1 篇
- ✅ 播种幂等：只在本地无数据时全量写入；重复启动与「补齐内置日记」都按 id 去重，不会产生重复
- ✅ 本地编辑保护：内置播种只补缺失记录，绝不覆盖你在手机上改过的内容
- ✅ 「数据」页：篇数/字符数/月份分布/标签统计，导入导出 JSON（详见下节）

**v1.1 新增**

- ✅ 分类标签：编辑页添加标签，或正文输入 `#标签` 自动提取；列表页标签栏一键筛选
- ✅ 图片附件：每篇最多 9 张，支持预览与删除，本地持久化
- ✅ 语音附件：录音（最长 10 分钟）附加到笔记，可试听、可删除（不转文字）
- ✅ 快速模板：内置 日记 / 待办清单（`- [ ]` 复选语法，列表显示 ☐ ☑）/ 会议纪要，**内置模板可修改**（可恢复默认），支持自定义模板
- ✅ 回收站（软删除）：删除先入回收站，可恢复、彻底删除、清空
- ✅ 快速筛选：按标签 / 按创建月份筛选，可与关键词叠加
- ✅ 标签预设与快捷选择：预设标签 + 历史标签点选即加，新标签直接输入；按「常用 → 最近」排序，长按可删除标签
- ✅ 分享为图片：笔记渲染成长图，可保存到相册或直接发送给微信朋友

## 快速开始

1. 下载安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)；
2. 打开开发者工具 → 「导入项目」→ 选择本目录；
3. AppID 可先选「测试号」（本项目配置为 touristappid，游客模式可直接预览）；
4. 编译运行即可看到笔记列表页。

> 无第三方依赖、无需云环境；真机体验录音与"发送给朋友"需要注册 AppID（游客模式部分能力受限）。

## 内置日记与数据同步

### 内置日记是哪来的

2026-10-14 从「贴贴密笺」App 导出全部日记（`贴贴密笺_2026-10-14_补全.json`），经 `tools/build_seed.py` 转换成小程序数据模型，生成 `data/seed-diary.js`（47篇 / 28383 字）。

| 原字段 | 小程序字段 | 说明 |
| --- | --- | --- |
| `id` | `id` | 保留原 UUID，导入时幂等去重 |
| `title` / `content` | 同名 | markdown 原文完整保留 |
| `category_id` | `tags` | 分类名直接作为标签：生活 45 / 重要 1 / 工作 1 |
| `created_at` / `updated_at` | `createdAt` / `updatedAt` | ISO 本地时间 → 毫秒时间戳 |
| `is_pinned` / `is_deleted` | `pinned` / `deletedAt` | 本批数据均为未置顶、未删除 |
| `color` | `color` | 便签底色，页面暂未使用，先留存 |

数据分布：2026-06 共 14 篇、07 共 11 篇、08 共 11 篇、09 共 9 篇、10 共 2 篇。

### 播种规则（`app.js` → `store.seedOnce()`）

1. 用 `seed_imported_version` 标记位记录是否已播种，**只执行一次**；
2. 本地无任何笔记 → 全量写入 47篇；
3. 本地已有笔记 → 只按 id 补齐缺失的，**绝不覆盖**你改过的内容；
4. 任何时候可从「数据」页点「补齐内置日记」手动重跑一次（`store.reseed()`）。

### 换手机 / 多设备同步

数据全部在本机 `wx.storage`，不联网。三种方式：

1. **开发者工具预览**（推荐，代码改动后立即生效）：`cli.bat preview --project <路径>`，手机微信扫码即可看到最新数据；
2. **导出 → 导入**：「数据」页「导出备份 JSON」把文件发到微信聊天 → 新设备「从微信导入 JSON」选该文件，可选「合并」（跳过同 id）或「覆盖同 ID」；
3. **代码内置**：日记本身已随包发布，新设备首次打开即自动播种，无需额外操作。

### 重新导入或校验

```bash
# 从新的导出文件重新生成种子数据
python tools/build_seed.py "C:/path/贴贴密笺_xxx.json"

# 离线校验：条数 / 逐字段正文 / 时间戳 / 分类标签 / 导入模式往返一致
node tools/verify_seed.js "C:/path/贴贴密笺_xxx.json"
```

## 技术要点

- **原生框架**：WXML + WXSS + JavaScript，基础库 ≥ 2.20.1（发送图片给朋友需 2.22.1+）；
- **数据模型**：`{ id, title, content, tags, images, audio, pinned, createdAt, updatedAt, deletedAt }`，整体存于本地存储 `notes` 键，旧数据缺字段自动兼容；
- **附件持久化**：`wx.chooseMedia` / 录音产生的是临时文件，保存笔记时复制到 `wx.env.USER_DATA_PATH/notes/`；彻底删除笔记时同步清理文件；
- **软删除**：删除 = 写入 `deletedAt` 标记，回收站可恢复；仅"彻底删除/清空"才移除记录与文件；
- **分享长图**：Canvas 2D 按逻辑尺寸 375×640 绘制（自动断行、标签胶囊、复选符号、首图 cover 裁切），导出 2 倍图；
- **分层设计**：页面层只做交互渲染，数据读写全部经由 `utils/store.js`，后续可平滑替换为微信云开发数据库。
