# 天天记 · 微信笔记小程序

一款免登录、离线可用、数据留在本机的轻量笔记小程序。打开即写，支持标签、图片与语音附件、快速模板、回收站、按标签/月份筛选、分享为图片。

需求、用例与验收标准见 [需求分析.md](./需求分析.md)。

## 功能一览

**基础（v1）**

- ✅ 新建笔记：标题（可选，≤50 字）+ 正文（不限长）
- ✅ 编辑笔记：回填内容，保存后自动更新时间与排序
- ✅ 笔记列表：置顶优先，其余按最后编辑时间倒序，卡片显示摘要与人性化时间（今天/昨天/日期）
- ✅ 关键词搜索：标题 + 正文模糊匹配，实时过滤
- ✅ 置顶/取消置顶：长按列表项操作
- ✅ 空状态：无笔记引导创建、搜索无结果提示

**v1.1 新增**

- ✅ 分类标签：编辑页添加标签，或正文输入 `#标签` 自动提取；列表页标签栏一键筛选
- ✅ 图片附件：每篇最多 9 张，支持预览与删除，本地持久化
- ✅ 语音附件：录音（最长 10 分钟）附加到笔记，可试听、可删除（不转文字）
- ✅ 快速模板：内置 日记 / 待办清单（`- [ ]` 复选语法，列表显示 ☐ ☑）/ 会议纪要，**内置模板可修改**（可恢复默认），支持自定义模板
- ✅ 回收站（软删除）：删除先入回收站，可恢复、彻底删除、清空
- ✅ 快速筛选：按标签 / 按创建月份筛选，可与关键词叠加
- ✅ 标签预设与快捷选择：预设标签 + 历史标签点选即加，新标签直接输入；按「常用 → 最近」排序，长按可删除标签
- ✅ 分享为图片：笔记渲染成长图，可保存到相册或直接发送给微信朋友

## 目录结构

```
├── app.js / app.json / app.wxss   # 小程序入口与全局配置、全局样式
├── project.config.json            # 开发者工具项目配置
├── sitemap.json                   # 收录配置
├── utils/
│   ├── store.js                   # 笔记数据存取层（CRUD + 标签聚合 + 预设标签 + 软删除 + 排序）
│   ├── util.js                    # ID 生成、时间格式化、月份键、判空、摘要提取
│   ├── templates.js               # 快速模板（内置可改 + 自定义，存于 builtin_overrides / custom_templates）
│   └── files.js                   # 附件持久化与清理（用户目录 USER_DATA_PATH/notes/）
└── pages/
    ├── index/                     # 笔记列表页（搜索/标签/月份筛选/置顶/删除/分享入口）
    ├── edit/                      # 编辑页（模板/标签点选与输入/图片/语音，新建与编辑复用）
    ├── recycle/                   # 回收站（恢复/彻底删除/清空）
    ├── share/                     # 分享页（canvas 生成长图，保存相册/发送朋友）
    ├── templates/                 # 模板管理（列表，跳转编辑页）
    └── template-edit/             # 模板新建/编辑页（与笔记编辑页同布局）
```

## 快速开始

1. 下载安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)；
2. 打开开发者工具 → 「导入项目」→ 选择本目录；
3. AppID 可先选「测试号」（本项目配置为 touristappid，游客模式可直接预览）；
4. 编译运行即可看到笔记列表页。

> 无第三方依赖、无需云环境；真机体验录音与"发送给朋友"需要注册 AppID（游客模式部分能力受限）。

## 技术要点

- **原生框架**：WXML + WXSS + JavaScript，基础库 ≥ 2.20.1（发送图片给朋友需 2.22.1+）；
- **数据模型**：`{ id, title, content, tags, images, audio, pinned, createdAt, updatedAt, deletedAt }`，整体存于本地存储 `notes` 键，旧数据缺字段自动兼容；
- **附件持久化**：`wx.chooseMedia` / 录音产生的是临时文件，保存笔记时复制到 `wx.env.USER_DATA_PATH/notes/`；彻底删除笔记时同步清理文件；
- **软删除**：删除 = 写入 `deletedAt` 标记，回收站可恢复；仅"彻底删除/清空"才移除记录与文件；
- **分享长图**：Canvas 2D 按逻辑尺寸 375×640 绘制（自动断行、标签胶囊、复选符号、首图 cover 裁切），导出 2 倍图；
- **分层设计**：页面层只做交互渲染，数据读写全部经由 `utils/store.js`，后续可平滑替换为微信云开发数据库。
